# Mục lục tài liệu

Chỉ mở file liên quan đến việc đang làm. Mỗi file chỉ nói về một chủ đề.

| File | Nội dung | Đọc khi |
|------|----------|---------|
| [scope.md](scope.md) | Tính năng có làm / không làm, luồng người dùng | Thêm hoặc bỏ tính năng, không chắc việc gì nằm trong phạm vi |
| [ui.md](ui.md) | Các màn hình, responsive, phím tắt | Làm hoặc sửa giao diện |
| [architecture.md](architecture.md) | Hosting, công nghệ, cấu trúc thư mục, quy tắc phụ thuộc, quy tắc `Repository` | Tạo file/module mới, thêm thư viện, động vào tầng `data/` |
| [data-model.md](data-model.md) | Các bảng, ràng buộc toàn vẹn, sao lưu JSON, migration | Sửa kiểu dữ liệu, schema, xuất/nhập |
| [learn-algorithm.md](learn-algorithm.md) | Chọn từ, loại câu hỏi, chấm điểm, trường hợp biên | Làm `domain/learn/` hoặc màn Learn |
| [streak.md](streak.md) | Quy tắc tính ngày học và chuỗi ngày | Làm `domain/streak/` hoặc ô streak |
| [security.md](security.md) | XSS, dữ liệu không tin cậy, secret, CSP | Xử lý input, render nội dung người dùng, CI |
| [cloud-sync.md](cloud-sync.md) | Giai đoạn 7: đăng nhập, Supabase, iPhone | Chỉ khi làm giai đoạn 7 |
| [decisions.md](decisions.md) | Nhật ký quyết định đã chốt và lý do | Trước khi đề xuất đổi một quyết định đã có |

Kế hoạch và tiến độ: [../PROGRESS.md](../PROGRESS.md).

**Quy tắc ghi tài liệu:** mỗi file dưới ~150 dòng; quá dài thì tách tiếp và thêm dòng vào bảng trên. Quyết định mới ghi vào `decisions.md`, nội dung chi tiết ghi vào file chủ đề.
